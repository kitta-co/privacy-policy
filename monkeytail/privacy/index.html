Privacy policy

Monkeytail

Last updated: September 22, 2026.

Kitta Co does not collect any data through Monkeytail. The app has no analytics, advertising, tracking, telemetry, account system, or developer-operated backend.

About the app

Monkeytail is an HTTP and cURL client provided by Kitta Ltd, trading as Kitta Co. It helps you create API requests and inspect responses on your iPhone or iPad.

Your device

Collections, request definitions, headers, bodies, environments, proxy settings, scripts, and request history are saved locally using iOS file protection. These can include credentials you enter. Response bodies stay in memory unless you choose to export them. Device backups are managed by your Apple settings; Monkeytail does not operate a sync service.

Connections you choose

When you send a request, the app connects to the API server and any proxy you select. Those services receive the request information needed to handle it, including any headers, body, credentials, and network address. Their operators control their own data practices. Kitta does not receive a copy. No request is sent merely by importing a collection.

Files and scripts

The app reads files you select for import and writes or shares files you explicitly export. Exports can contain saved credentials. JavaScript hooks execute locally in an isolated context with network access blocked. Imported scripts are disabled until you choose to enable them.

Your choices

You can edit or delete local collections, requests, and environments, clear history, change proxies, or remove the app to remove its local data. Files you exported and device backups remain under your control. Data sent to an API server or proxy is managed by that service.

Support

If you voluntarily email support@ieb.app, we receive the information you include and use it to respond. This is separate from app operation. Do not include passwords, tokens, or private request contents.

Changes

We will update this page if the app’s data practices change. The date above identifies the latest revision.
