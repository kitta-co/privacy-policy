Send a request

Choose a saved request or add one, enter a complete HTTP or HTTPS URL, and tap Send. Use the request tabs to edit headers, parameters, body, authentication, and scripts. Response shows status, timing, headers, and body. Tap Pretty or Tree for JSON, or search the response text.

Import cURL

Open the workspace actions menu, choose Import, and paste a cURL command. Shell quoting and multiline commands are parsed as text; Monkeytail never executes a shell. Multipart -F/--form-string and file-body imports are supported. Imported paths never read device files automatically: choose each attachment in Body using Files or Photos. Unsupported flags produce an explicit error.

Import and export collections

Use the workspace actions menu to import pasted JSON or a file from Files. Imports append collections and environments. Native Monkeytail workspace exports preserve all settings, including proxy settings. Review imported content before sending requests or enabling scripts.

  • Postman: v2/v2.1 collection JSON and environment JSON import; v2.1 collection export with the active environment as collection variables.
  • Insomnia: v4 JSON import and export. Convert YAML or newer formats to supported JSON in the source tool first.
  • Monkeytail: complete workspace JSON import and export.

Third-party formats do not preserve every setting. Nested environment inheritance, dynamic template tags, the complete Postman or Insomnia scripting runtimes are not supported.

Tools added in 1.2

The native Mac app uses the same optional iCloud workspace as iPhone and iPad, without Monkeytail accounts. Collection and folder defaults supply headers, authentication, variables, and scripts. Requests can choose Inherit authentication.

Auth supports API keys, OAuth 2.0 authorization code with PKCE and refresh, client credentials, and AWS SigV4. Register monkeytail://oauth as the OAuth redirect. Enable Use cookie jar per request; edit jars and exact-host PKCS#12 identities in Cookies & certificates. Client certificates require System TLS; Mac import requires macOS 15.

Import Swagger 2 or OpenAPI 3 JSON/YAML with bundled local references. Tests offers status/time/header/JSONPath checks and a bounded portable JSON Schema subset; unsupported advanced keywords report an error. Add a schema assertion to validate a response. GraphQL offers query, variables, operation selection, introspection, and searchable field suggestions.

Choose WebSocket or SSE in the protocol menu, then Connect. The message timeline can filter, reconnect, and inspect text/JSON/binary. Code export supports Swift, JavaScript, Python, and Kotlin, with credential hiding enabled by default. Inspect arbitrary bodies and attachments before sharing.

Mock enables offline UTF-8 responses with status, headers, delay, or errors. Reuse a current response or snapshot. The optional foreground mock server matches method and path on a loopback-only port; it is not reachable by other devices.

Upload files

In Body, choose Multipart for text fields and file attachments, or File for a binary body. Select files from Files or photos/videos from Photos. MIME types are editable. Native exports include file bytes. Postman, Insomnia, and cURL exports reference filenames; use Export file in Body to move attachments beside those exports.

Diagnostics and saved responses

Diagnostics shows per-hop DNS, connection, TLS, upload, server, and download timings, transport-reported headers, and sent bodies. Unreported phases show a dash. Use the response menu to save a snapshot, compare JSON/status/headers against a saved response, or extract JSONPath values. JSONPath supports the root, keys, array indices, and wildcards. Snapshots are local and searchable from the workspace menu.

Optional iCloud sync

Enable iCloud sync in Connection settings to share collections, environments, and scripts through your device’s existing iCloud Drive session. No app account. Requests remain usable offline. Credentials, cookie jars, client identities, secret fields, upload bytes, snapshots, and history stay local. Mark a variable or field local with its lock/options menu. Review bodies and scripts for embedded secrets. Edits to different requests merge; the latest edit wins for the same request. Toggle sync off and on after changing the device’s iCloud session.

Environments and scripts

Use {{variable}} in request fields and choose a named environment. Scripts offer a small pm compatibility API for variables, requests, responses, assertions, and tests. Scripts are local, time limited, and cannot make separate network requests. Imported scripts start disabled.

Proxies and connections

Settings offers system networking or a custom HTTP CONNECT, HTTPS CONNECT, or SOCKS5 proxy. Supply the host, port, and optional credentials. A failed custom proxy does not fall back to a direct connection. Allow local-network access in iOS Settings to reach LAN APIs. TLS certificate verification remains enabled; a debugging CA must be installed and trusted in iOS when required.

Limits

Imports are limited to 40 MB; uploads and responses to 20 MB. Sync metadata is limited to 20 MB. JSONPath and JSON comparisons support bodies up to 2 MB. Saved snapshots retain up to 50 entries within 60 MB. Text and tree previews are limited to 1 MB, while the full received response can be saved. Recent history keeps up to 50 request definitions. JavaScript execution has a three-second deadline.

Report a problem

Email support@ieb.app with the app version, operating-system version, affected feature, and a minimal non-sensitive example. Remove tokens, passwords, private headers, and personal information before sharing. No diagnostic information is uploaded automatically.
