Monkeytail

HTTP & cURL for iPhone.

Import a command. Edit a request. Inspect the response. A native SwiftUI API client, made for iPhone and ready for iPad.

Free. No in-app purchases. No account. No data collected.

App Store release in preparation. Get help

Your API workspace, in your pocket

  • Requests: cURL import and export, headers, parameters, JSON and form bodies, basic and bearer authentication.
  • JSON: formatted text, syntax colors, expandable trees, search, copy, and response file export.
  • Collections: local workspaces, named environments, variables, and recent request history.
  • JavaScript: local before-request and after-response hooks, assertions, console output, and environment updates.
  • Proxies: system networking, HTTP CONNECT, HTTPS CONNECT, or SOCKS5, with optional authentication.

Bring your existing requests

Import Postman collection and environment JSON, or Insomnia v4 JSON. Export Postman v2.1 collections, Insomnia v4 JSON, cURL, or a complete Monkeytail workspace. See supported formats.

Designed around the phone

Send and switch views from the bottom of the screen. Headers stay compact and readable. Wider windows show request and response side by side. Supports dark mode, Dynamic Type, VoiceOver labels, and keyboard shortcuts.

Local by design

Kitta Co collects no data through Monkeytail. There are no analytics, ads, tracking, or cloud accounts. Your requests go to the servers and proxies you select. Read the privacy policy.

Requires iOS or iPadOS 17 or later.
