Monkeytail

HTTP & cURL for iPhone.

Import a command. Edit a request. Inspect the response. A native SwiftUI API client, made for iPhone and ready for iPad.

Free. No in-app purchases. No account. No data collected.

Download on the App Store. Get help

Your API workspace, in your pocket

  • Requests: cURL import and export, headers, parameters, JSON, form, multipart, and file bodies, basic and bearer authentication.
  • JSON: formatted text, syntax colors, expandable trees, search, copy, and response file export.
  • Collections: local workspaces, named environments, variables, recent history, and optional iCloud Drive sync without an app account.
  • Responses: media previews, Hex/Binary viewers, saved snapshots, JSON/header comparisons, and JSONPath extraction.
  • Diagnostics: per-hop connection/TLS/server timings and transport-reported headers.
  • JavaScript: local before-request and after-response hooks, assertions, console output, and environment updates.
  • Proxies: system networking, HTTP CONNECT, HTTPS CONNECT, or SOCKS5, with optional authentication.

API tools

A native Mac app with shared optional iCloud workspaces. Nested folders, OAuth 2.0, API keys, AWS signing, cookie jars, client certificates, visual tests, OpenAPI import, GraphQL, WebSocket/SSE, client code export, and offline mocks. No Monkeytail account. These tools are included in the 1.3 update submitted for App Store review.

Bring your existing requests

Import Postman collection and environment JSON, or Insomnia v4 JSON. Export Postman v2.1 collections, Insomnia v4 JSON, cURL, or a complete Monkeytail workspace. See supported formats.

Designed around the phone

Send and switch views from the bottom of the screen. Headers stay compact and readable. Wider windows show request and response side by side. Supports dark mode, Dynamic Type, VoiceOver labels, and keyboard shortcuts.

Apple Vision Pro and Watch

A native visionOS workspace with optional iCloud sync, plus a simple Apple Watch companion. Star requests on iPhone, copy favourites to your paired Watch, and send or cancel requests with a compact response viewer. No Monkeytail accounts. Version 1.3 is submitted for App Store review.

Local by design

Kitta Co collects no data through Monkeytail. There are no analytics, ads, tracking, or Monkeytail accounts. Optional sync uses your existing iCloud Drive; credentials and marked secrets stay on your device by default. Your requests go to the servers and proxies you select. Read the privacy policy.

Requires iOS or iPadOS 17 or later.
